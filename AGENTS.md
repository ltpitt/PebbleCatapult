# Agent Instructions

## Planning

Apply repository-wide rules to every implementation plan and screen variant.
When Android-specific work is involved, also follow
[`mobile/AGENTS.md`](mobile/AGENTS.md).
When watch-specific work is involved, also follow
[`watch/AGENTS.md`](watch/AGENTS.md).

## Documentation and scope

Keep Android-specific guidance in [`mobile/AGENTS.md`](mobile/AGENTS.md) and
watch-specific guidance in [`watch/AGENTS.md`](watch/AGENTS.md); avoid
duplicating component guidance here. When changing important functionality,
update `README.MD` and any other affected user-facing instructions or reference
documentation. If no documentation update is needed, state that assessment in
the implementation notes or review description.
